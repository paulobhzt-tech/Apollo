## Gate antes de solicitar execução concreta

- [ ] Titular escolheu VPS existente ou host novo e aprovou o orçamento/prazo. Recomendação preparada: host temporário isolado; preço ainda não cotado.
- [ ] Inventário e parecer de capacidade, versões instaladas, conflitos de rede/portas e SELinux disponíveis para o host escolhido.
- [ ] Responsável pelo site existente aprovou qualquer leitura ou mudança que possa envolvê-lo; backups/restauração comprovados se a VPS for considerada.
- [ ] Artefato Web distribuível e verificável existe; imagem/base/arquitetura, Mongo e proxy têm digests registrados. Não confundir imagem local de runner com registry publicado.
- [ ] Configuração final revisada preserva isolamento/limites, monta só segredos necessários e remove bootstrap após uso; sem credenciais reais, mounts do site ou egress de pagamento/SEFAZ.
- [ ] DNS/TLS/proxy/firewall restritos têm diff exato, baseline e rollback; nenhuma configuração global compartilhada será modificada sem autorização específica.
- [ ] Backup fictício criptografado e restore em outro destino têm procedimento operacional revisado e evidência; RPO/RTO/responsáveis definidos.
- [ ] Testadores/horários/IPs/VPN/contas, dispositivos e casos obrigatórios escolhidos, com evidências protegidas e parada financeira conhecida.
- [ ] Proposta concreta lista somente os comandos/mudanças autorizados, com janela, limites e ação de reversão. Não solicitar um “pode fazer tudo?” genérico.
